# Draftsman Co-Authoring & Automated PR Skill

## Purpose
Enables the Draftsman Agent to interactively interview software engineers, generate valid DRAFT architecture YAML files (`product_component`, `data_store_service`, `runtime_service`, `edge_gateway_service`, `software_deployment_pattern`), validate the workspace with `validate.py`, and automatically commit, push, and open Pull Requests against the company's DRAFT workspace repository.

---

## Workflow Steps

### Step 1: Interactive Design Interview
1. **Search Catalog:** Query existing `catalog/` to check if components or deployment patterns already exist.
2. **Identify Missing Facts:** Ask minimal, structured questions to capture:
   - Component name & primary programming runtime (Python, Java, Node.js, C#).
   - Ingress boundary (ALB, API Gateway, CloudFront, Internal Only).
   - Datastores & messaging queues (PostgreSQL, DynamoDB, Redis, SQS, Kafka).
   - Infrastructure-as-code format (CDK, Terraform, Helm).

### Step 2: Write Schema-Validated YAML
1. Read authoritative schemas under `.draft/framework/schemas/`.
2. Construct valid YAML objects inside the appropriate domain path under `catalog/` (e.g. `catalog/engineering/<domain>/`).
3. Ensure required fields are present (`type`, `id`, `name`, `businessContext`, `technologyComponents`).

### Step 3: Run Workspace Validator
Execute the workspace validator:
```bash
python3 .draft/framework/tools/validate.py --workspace .
```
If errors or warnings occur, fix missing attributes before proceeding.

### Step 4: Automated Git & Pull Request Execution
Execute automated Git operations to open a PR on the company workspace repo:

```bash
# 1. Create short-lived feature branch
git checkout -b draft/<feature-name>

# 2. Stage new/updated catalog files
git add catalog/ configurations/ docs/

# 3. Commit with semantic message
git commit -m "feat(draft): add <feature-name> architecture catalog entries"

# 4. Push branch to remote
git push origin draft/<feature-name>

# 5. Open Pull Request on company repository
gh pr create \
  --title "feat(draft): add <feature-name> architecture catalog entries" \
  --body "Automated DRAFT architecture catalog PR generated by Draftsman. Validated with 0 errors."
```

### Step 5: Respond to User with PR & Preview Links
Present the PR link and GitHub Pages catalog browser link directly in the chat interface (Slack, Discord, Web UI).
